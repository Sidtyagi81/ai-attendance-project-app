# 🎓 AI Attendance System

> **An AI-Powered Attendance Management Platform using Face Recognition and Voice Authentication**

AI Attendance System is a smart attendance management application that automates attendance recording using Artificial Intelligence. The platform verifies users through facial recognition and voice authentication, stores attendance records securely, provides analytics, and generates attendance reports through an interactive Streamlit dashboard.

---

# 🚀 Features

## 🎭 Face Recognition Attendance

* Detects and recognizes registered users.
* Automatically marks attendance.
* Eliminates manual attendance processes.

## 🎤 Voice Authentication

* Additional verification using voice recognition.
* Improves security and authentication accuracy.

## 👨‍🎓 Student Management

* Register new users.
* Manage student records.
* Secure user authentication.

## 📊 Dashboard & Analytics

* Total attendance records.
* Attendance statistics.
* Performance visualization.
* Historical attendance tracking.

## 📈 Reports

* Attendance summaries.
* Daily attendance reports.
* User-wise attendance history.

## 🔐 Authentication

* Login & Signup System.
* Secure SQLite database integration.
* User-specific access.

# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Sidtyagi81/ai-attendance-system.git
```

### Navigate to Project

```bash
cd ai-attendance-system
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
streamlit run app.py
```
